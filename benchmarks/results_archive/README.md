# Historical Results Archive

This directory contains results from previous benchmark runs and experiments.

- `real_results.json`: Baseline results from real-world verification.
- `results.json`: Combined results from various runs.
- `snap_plus_results.json`: Results for the SNAP+ optimizer variant.
- `snap_pp_results.json`: Results for the SNAP++ optimizer variant.
- `S7_PLUS_RESULTS.json`: Results for the S7+ optimizer variant.
