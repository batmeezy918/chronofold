# Verified Theorems

Canonical index for theorem artifacts with current-tree Lean evidence.

Promotion requires: current source, successful Lean verification, no `sorry`, no narrative-only claim, no historical-PR-only evidence, and an exact source hash in `MANIFEST.json`.

This directory is an auditable promotion/index layer; source modules remain authoritative.

Current promoted families:
- AGD core definitions and admissibility
- AGD equivalence, quotient, projection, descent, and soundness
- AGD invariants and admissible descent
- AGD compositional closure
- CFPC kernel equivalence
- T1 smoke theorem

Historical or narrative claims are not promoted automatically.
