## Node and Edge Descriptions

### 1. Foundational Types
- **State (node):** Represents the operational state structure holding the id and payload.
- **Omega & Covariant (nodes):** System specifications and invariant properties.
- **Operator (node):** Maps states to states.

### 2. Relations and Sets
- **AGDEquiv (node):** Equivalence relation generated by the invariant pair.
- **agdSetoid (node):** The formal Setoid instance proving reflexivity, symmetry, and transitivity.
- **QStar (node):** The quotient type derived from the Setoid.
- **pi (node):** The canonical quotient projection map.

### 3. Morphisms and Lifting
- **TBar (node):** Lifting of an admissible operator $T$ to the quotient state space.
- **TBar_sound (node):** Proof that $\bar{T} \circ \pi = \pi \circ T$.
- **descends (node):** Existence proof of the quotient-lifted operator.
- **uniqueMorph (node):** Uniquely constructs the morphism from the initial object $Q^*$.

### 4. Algebraic Closure
- **uniqueMorph_unique (node):** Proves the universal property/uniqueness of `uniqueMorph`.
- **admission_iff_descends (node):** Proof that admissibility is equivalent to the descended map acting as the identity.

### 5. Metamodel and Replay Stability
- **Replay (node):** Sequence replay function.
- **AllAdmissible (node):** Invariant list validator.
- **replay_preserves_invariants (node):** Proves that sequential replay of any number of admissible operators preserves the system invariants.
